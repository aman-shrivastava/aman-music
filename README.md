# Aman Music

A personal offline music player built as a hands-on DevOps project.

## Goal

Build, test, containerize, deploy and monitor a personal music player while learning DevOps end-to-end.

## Planned Technologies

- Python / FastAPI
- HTML / CSS / JavaScript
- PostgreSQL
- Git / GitHub
- Docker
- GitHub Actions
- Terraform
- Azure
- Kubernetes
- Prometheus
- Grafana
